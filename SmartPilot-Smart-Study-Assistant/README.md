# StudyPilot – Smart Study & Task Planner

StudyPilot is a modular Python-based study productivity engine, interactive web prototype, and Flask REST API designed for academic workflow optimization, priority management, and task analytics.

## 🚀 Quick Start & Installation

### 1. Run Interactive Prototype
Open `prototype/index.html` in any modern web browser to interact with the visual dashboard prototype.

### 2. Run Python Backend API
```bash
pip install -r requirements.txt
python src/app.py
```
Access the backend server at `http://localhost:5000`.
